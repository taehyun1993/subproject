대상 문서: $ARGUMENTS

문서를 **재검토하고 다시 쓴다**. (`/docs`가 현황 파악이라면 이건 품질 개선이다.)

1. **비평** — 대상 문서를 읽고 중복·누락·모순·낡음·실제 동작과의 괴리를 구체적으로 짚는다(파일·섹션 단위).
2. **수정안 제시** — 어떻게 고칠지 diff 형태로 보여준다. 큰 구조 변경이면 먼저 개요를 합의한다.
3. **승인 후 반영** — 사용자가 승인한 부분만 반영한다. **원본을 바로 덮어쓰지 않는다.**
4. 다른 문서의 섹션 번호를 참조하는 경우, 번호가 깨지지 않게 점검한다.

큰 구조 변경이면 `/docs`로 현황(인덱스·관계·중복)을 먼저 파악한 뒤 진행한다.
