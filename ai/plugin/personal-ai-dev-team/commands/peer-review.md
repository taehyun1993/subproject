현재 작업을 외부 AI에 검토 위임한다. 대상: $ARGUMENTS (생략 시 현재 변경분/대화 맥락)

## 조직 정책 게이트 (먼저 확인 — 어기면 중단)

외부 AI(현재 Codex/OpenAI)는 **외부 서비스**다. 조직 정책상 사내 코드·아키텍처·비즈니스 로직·고객 데이터의 외부 공유는 제한된다. 따라서:

1. **sanitize 필수** — 전달 전 다음을 차단/마스킹한다: PII(실명·전화·이메일·주소·주민번호), 결제·계좌 정보, 자격증명(AWS 키·API 키·DB 접속정보·JWT·.env 값), 핵심 비즈니스 로직. (hooks의 `pii-guard.mjs` 기준과 동일)
2. **범위 제한** — 일반 코드·구조·설계 위주로만 전달한다. **운영 DB·고객 데이터·실제 자격증명은 전달하지 않는다.**
3. **차단 핵심이면 중단** — sanitize로 가려야 할 부분이 검토의 핵심이면, 외부 위임을 멈추고 사용자에게 알린 뒤 내부 검토(`/docs-refine`, 내부 code-review)를 권한다.

## 위임 → 결과 처리

4. sanitize된 내용으로 외부 AI에 검토를 요청한다. 현재 백엔드는 **Codex(로컬 CLI 우선)**. (다른 AI로 교체 가능하게 일반화된 기능이다.)
5. 받은 검토 의견을 요약하고, **반영 여부는 사용자가 판단**한다(자동 반영 안 함).

> 무엇을 외부로 보내는지 사용자에게 먼저 요약해 보여주고 동의를 받은 뒤 전송한다.
